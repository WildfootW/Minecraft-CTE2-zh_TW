# CTE2 1.1.3 模組語言檔翻譯規範(譯者 agent 必讀)

你要把 Minecraft 模組的語言檔 JSON(key → 英文值)翻成道地台灣繁體中文。這是 Craft to Exile 2 模組包(Path of Exile 風格 ARPG)的核心模組 Mine and Slash 及其附屬模組。

## 輸出格式

- 讀入的 chunk 是 JSON 物件(key → English)。輸出**同樣的 JSON 物件**:key 一字不改、順序不變,只把 value 翻成繁中。
- 輸出必須是**合法 JSON**(UTF-8 無 BOM,中文直接寫字面,不要 \uXXXX 轉義)。
- 用 Write 工具寫到指定輸出路徑。

## 絕對規則

1. **佔位符原樣保留**:`[VAL1]`、`[VAL2]`、`[calc:xxx]`、`%s`、`%1$s`、`%d` 等,一個都不能動、不能翻、不能刪。
2. **§ 顏色碼原樣保留**:`§a`、`§b`、`§7`、`§6` 等,位置跟著對應詞走。特殊符號(★☀✦等)保留。
3. **前後空格與結尾冒號保留**:原值結尾是 `: ` 就保留 `：`(改用全形冒號可,但空格結構要合理)。原值結尾有空格的保留空格。
4. 值是空字串就保持空字串。
5. 純技術值(如只有佔位符、只有符號的值)原樣照抄。

## 風格

- 台灣用語,禁大陸用語。屬性/技能描述要簡潔精準,像正式遊戲在地化。
- 詞綴名(mmorpg.affix.*)是裝備前後綴名詞(如 Archeologist's → 考古學家的),簡短有力。
- 傳奇裝備名(mmorpg.unique_gear.*.name)可用意譯,帶史詩感。
- 聊天訊息(mmorpg.chat.*)口語自然。
- 天賦名(mmorpg.talent.*)簡短,Major X → 高階X、Minor X → 初階X 之類保持系統性。
