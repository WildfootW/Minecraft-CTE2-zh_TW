# CTE2 1.1.3 任務書翻譯規範(譯者 agent 必讀)

你要把 FTB Quests 的 .snbt 檔案裡的**顯示文字**翻成道地的台灣繁體中文。這是 Craft to Exile 2(Path of Exile 風格的 Minecraft 模組包)的任務書。

## 絕對規則(違反會弄壞遊戲檔案)

1. **輸出檔的總行數必須與來源檔完全相同**。逐行對應,只改可翻譯行的引號內文字,其他行原封不動照抄(包含 tab 縮排)。
2. **只能翻譯**以下欄位引號內的文字:
   - `title: "..."`
   - `subtitle: "..."` (也可能是 `subtitle: [ ... ]` 陣列,翻陣列裡的字串)
   - `description: [ ... ]` 陣列中的字串元素(整行只有一個 `"..."` 的行)
   - `hover: [...]` 與 `text: "..."`(圖片/連結的顯示文字)
3. **絕對不可更動**:
   - 任何 key 名稱(`title:`、`id:` 等冒號左邊的字)
   - `id:`、`icon:`、`item:`、`image:`、`filename:`、`group:`、`dependencies:` 等所有非顯示文字的值
   - 數字、布林值、座標、`{ ... }` 結構
   - 字串裡內嵌的 JSON(例如 `mmorpg_gear: "{\"baseStats\"...}"` 整個不碰)
   - 空字串 `""` 保持空
4. **保留格式碼**:`&a`、`&d`、`&r`、`&l`、`&9` 等顏色/樣式碼原樣保留在對應中文前後。`\"` 逸出引號、`\n`、`\\` 都要保留原語法。
5. description 陣列裡若有整行是 `{ image: ... }` 之類的物件,原樣照抄。
6. 檔案編碼:UTF-8(無 BOM)。用 Write 工具寫出。

## 翻譯風格

- 台灣繁體中文,用語自然口語、像台灣遊戲在地化,不要中國大陸用語(不用「视频/激活/内存」這類詞;用「影片/啟用/記憶體」)。
- 對玩家稱「你」。語氣輕鬆但資訊清楚,原文有幽默感就保留幽默感。
- Minecraft 官方台灣譯名:Nether=地獄、The End=終界、Ender Dragon=終界龍、Creeper=苦力怕、Villager=村民、Emerald=綠寶石、Netherite=獄髓、Elytra=鞘翅、Enchant=附魔。
- 專有物品名稱(玩家要去找/合成的特定物品)第一次出現時可用「中文（English）」附註原文,幫助玩家對照遊戲內英文物品名;一般概念詞不用附註。
- 模組名稱保留英文(例如 Mine and Slash、Botania、Sophisticated Backpacks)。
- Wiki、Discord 等保留英文。

## 產出

把翻譯完成的檔案用 Write 寫到指定的輸出路徑(prompt 會給)。最後回覆一行:翻譯了幾行文字、有沒有拿不準的術語(列出)。不要在回覆貼整份檔案內容。
